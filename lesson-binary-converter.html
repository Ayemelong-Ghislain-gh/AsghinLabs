Binary, Decimal and Hexadecimal Converter

Computers store every number as a row of bits. Flip the bits below to see how binary, decimal and hexadecimal are three ways of writing the same number. Then try the challenge.

Tap a bit to flip it between 0 and 1. Each place is worth double the one on its right. You can also type in any box.

How it works

  • Binary uses only 0 and 1. From the right, the places are worth 1, 2, 4, 8, 16, 32, 64, 128. A 1 means "count this place".
  • Binary → decimal: add up the place values that have a 1. For example 1010 0110 = 128 + 32 + 4 + 2 = 166.
  • Hexadecimal uses 16 digits: 0–9 then A=10, B=11, C=12, D=13, E=14, F=15. One hex digit stands for exactly 4 bits, so you convert each group of four separately.
  • Binary → hex: split into two groups of four, then turn each group into a digit. 1010 0110 → A and 6 → A6.
