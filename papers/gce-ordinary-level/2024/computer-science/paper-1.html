GCE O Level Computer Science 2024Paper 1 · answers & explanations

0595/1 · Multiple choice · 50 questions · 1 h 30 min

📄 Open the official paper ↗

Paper © Cameroon GCE Board, opened on the MINESEC platform. Open the paper, try each question, then check your answer here.

1Software that interprets HTML
🤖 Ask AI tutor

Answer: A

A web browser reads the HTML code of a page and displays it. Compilers and assemblers translate program code into machine code; they do not display web pages.

2Number of cells in a spreadsheet range
🤖 Ask AI tutor

Answer: A

The range runs over 5 columns (A, B, C, D, E) and 5 rows (1 to 5), so it has 5 × 5 = 25 cells.

3Binary subtraction
🤖 Ask AI tutor

Answer: B

Convert to decimal to check: 10101₂ = 21 and 1111₂ = 15. 21 − 15 = 6, and 6 in 4-bit binary is 0110.

4Control structure that repeats steps
🤖 Ask AI tutor

Answer: B

Iteration (a loop) repeats a block of instructions. Sequence runs steps one after another; selection chooses between paths.

5Check that data was received correctly
🤖 Ask AI tutor

Answer: D

A parity check adds an extra bit so the receiver can detect whether bits were changed during transmission. Format and length checks are for data entry, not transmission.

6Boosting a weak signal
🤖 Ask AI tutor

Answer: B

A repeater receives a weak signal, regenerates it and sends it on at full strength, so it can travel further.

7Type of software a DBMS is
🤖 Ask AI tutor

Answer: B

A database management system (such as MS Access) is used to carry out a user task, storing and querying data, so it is application software, not system software.

8Malware hidden inside a genuine-looking program
🤖 Ask AI tutor

Answer: C

A Trojan horse pretends to be useful, legitimate software while hiding harmful code. A virus attaches to files and a worm spreads by itself across networks.

9Computer with the highest throughput
🤖 Ask AI tutor

Answer: C

Two cores at 1.1 GHz can do about 2.2 GHz of work in parallel, and 4 GB is the most RAM (the maximum a 32-bit system can use). Option D runs at only 500 Hz, which is extremely slow.

10Storage units from smallest to largest
🤖 Ask AI tutor

Answer: C

Bit < Byte (8 bits) < Kilobyte (1024 bytes) < Terabyte.

11All computers connected to one central computer
🤖 Ask AI tutor

Answer: C

The computer in the control room acts as the server and the café computers are its clients: a client-server network. In peer-to-peer, all computers are equal.

12NOT a feature of a good algorithm
🤖 Ask AI tutor

Answer: B

A good algorithm must be precise and unambiguous, finish in finite time and follow a logical order. Being ambiguous is the opposite of what is needed.

13Domain name in a web address
🤖 Ask AI tutor

Answer: B

In https://www.cgceboard.cm/homepage.html, 'https' is the protocol, 'www' is the host, 'cgceboard.cm' is the domain name and 'homepage.html' is the file (page).

14Sending images over telephone lines
🤖 Ask AI tutor

Answer: B

A fax (facsimile) machine scans a document or image and sends it over a telephone line to another fax machine, which prints it.

15Identify the gate from its truth table
🤖 Ask AI tutor

Answer: D

The output is 1 only when the two inputs are different (0,1 and 1,0) and 0 when they are the same. That is the XOR (exclusive OR) gate.

16Flowchart symbol for input/output
🤖 Ask AI tutor

Answer: A

The parallelogram is used for input and output. The rectangle is a process, the diamond is a decision and the rounded shape (oval) is start/stop.

17Meaning of ATM
🤖 Ask AI tutor

Answer: B

ATM stands for Automated Teller Machine.

18'Wrong date and time' at start-up
🤖 Ask AI tutor

Answer: B

The date, time and BIOS settings are kept in CMOS memory, powered by a small battery. When the CMOS battery fails, the computer forgets the date and time.

19Type of construct 'If – Then – Else' is
🤖 Ask AI tutor

Answer: A

If–Then–Else chooses between two paths depending on a condition, so it is selection (decision).

20Circuit made of an OR gate followed by a NOT gate
🤖 Ask AI tutor

Answer: A

The OR gate's output goes into a NOT gate (the triangle with the small circle), which inverts it. NOT-OR is the NOR gate.

21Polite behaviour on the Internet
🤖 Ask AI tutor

Answer: B

Netiquette (net + etiquette) is the set of rules for respectful behaviour online.

22System that stores knowledge and imitates human reasoning
🤖 Ask AI tutor

Answer: C

An expert system holds the knowledge of human experts in a knowledge base and uses rules to reason and give advice, like a doctor or engineer would.

23Person responsible for time and quality of a project
🤖 Ask AI tutor

Answer: B

The project manager plans the project, follows its schedule and budget, and makes sure it is delivered on time with acceptable quality.

24A disadvantage of telebanking
🤖 Ask AI tutor

Answer: C

Options A and B are advantages. Because the account is reached over a network, a real disadvantage is the risk of accounts being hacked.

25Concentric rings on a magnetic disk
🤖 Ask AI tutor

Answer: B

Tracks are the concentric circles on the disk surface. Each track is divided into sectors.

26Using a new system alongside the old one
🤖 Ask AI tutor

Answer: D

Parallel running means the old and new systems are used at the same time until the new one is trusted. Direct changeover replaces the old system at once.

27A key advantage of social networks
🤖 Ask AI tutor

Answer: C

Social networks let users share rich media (photos, audio and video) instantly with many people. Informal language is not an advantage, and large file transfer is not their purpose.

28File a video program can open
🤖 Ask AI tutor

Answer: A

The extension .avi is a video format. .jpeg is an image, and .wav and .mp3 are audio files.

29What a compiler is
🤖 Ask AI tutor

Answer: C

A compiler translates the whole source code of a high-level program into machine code (object code) before it is run.

30Computer that processes discrete data
🤖 Ask AI tutor

Answer: D

Digital computers work with discrete values (0s and 1s). Analog computers use continuous data, and hybrid computers use both.

31Units of time in increasing order
🤖 Ask AI tutor

Answer: A

1 picosecond = 10⁻¹² s, 1 nanosecond = 10⁻⁹ s and 1 millisecond = 10⁻³ s, so picoseconds < nanoseconds < milliseconds.

32What Android is
🤖 Ask AI tutor

Answer: D

Android is an operating system for smartphones and tablets, made by Google.

33Component that says how operations are carried out
🤖 Ask AI tutor

Answer: C

Procedures are the rules and instructions that say how the people, hardware and software of an information system carry out each operation.

34ASCII code of 'a' from the code of 'd'
🤖 Ask AI tutor

Answer: C

01100100 = 100 in decimal. Letters are coded in order, and 'a' is 3 places before 'd', so 100 − 3 = 97 = 01100001.

35Name for a web address
🤖 Ask AI tutor

Answer: B

A web address is a URL: Uniform Resource Locator.

36Number of records for 150 students
🤖 Ask AI tutor

Answer: B

Each student is one record (one row), so 150 students give 150 records. The 5 headings are the fields (columns).

37Hardware that emits more radiation
🤖 Ask AI tutor

Answer: C

CRT (cathode ray tube) monitors fire electron beams at the screen and give off more radiation than flat LCD screens.

38Trying different values to see the effect
🤖 Ask AI tutor

Answer: B

Changing input values to see how the results change is what-if analysis, often done in a spreadsheet.

39What a dual-core computer is
🤖 Ask AI tutor

Answer: B

A dual-core processor has two processing units on one chip, so it can process about twice as much data as a single core. It does not double the motherboard, system unit or memory.

40Testing an algorithm with sample values
🤖 Ask AI tutor

Answer: C

A dry run means going through the algorithm by hand with test values (often using a trace table) to check that it gives the right result.

41Hexadecimal CD to binary
🤖 Ask AI tutor

Answer: A

Convert each hex digit to 4 bits: C = 12 = 1100 and D = 13 = 1101, so CD₁₆ = 11001101₂.

42How long a non-critical task can be delayed
🤖 Ask AI tutor

Answer: A

Slack (float) time is the time a task can be delayed without delaying the whole project. Tasks on the critical path have zero slack.

43System that switches itself off and on by temperature
🤖 Ask AI tutor

Answer: C

The system reads the temperature and acts on it automatically (switching off at 80 °C, on below 50 °C). Acting on the readings makes it a control system; a monitoring system only records them.

44NOT a physical (cable) medium
🤖 Ask AI tutor

Answer: A

Twisted-pair, coaxial and fibre-optic are cables (guided media). Microwaves travel through the air, so they are wireless (unguided) media.

45Chart for managing a project from start to finish
🤖 Ask AI tutor

Answer: B

A Gantt chart shows each task as a bar against time, from the start to the end of a project.

46Data type with only two values
🤖 Ask AI tutor

Answer: B

A Boolean holds only TRUE or FALSE (1 or 0).

47Comments in a program
🤖 Ask AI tutor

Answer: A

Comments are notes for programmers. The compiler ignores them, so they are never compiled into the program.

48Protecting archived files from unauthorised access
🤖 Ask AI tutor

Answer: A

Access to stored files is usually controlled with a password. Encryption also protects files, by making them unreadable without the key; antivirus and backups do not stop unauthorised access.

49Interface where you click on commands
🤖 Ask AI tutor

Answer: A

A graphical user interface (GUI) lets the user click on icons, menus and buttons. A command line interface needs typed commands.

50Device that splits one channel into many
🤖 Ask AI tutor

Answer: D

A demultiplexer takes one combined channel and splits it back into several. A multiplexer does the opposite: it combines several signals into one channel.
